# Cadastro de alunos — exercício de listas

Exercício de entrada de nomes e notas, armazenamento dos dados em listas e início de uma listagem usando índices.

## Como executar

```bash
python cadastro_alunos.py
```

## Conceitos praticados

- `while`
- Entrada e conversão de dados
- Listas e `append()`
- Cópia de listas com `dados[:]`
- Percorrer listas com `for` e `range()`

**Observação:** este arquivo contém apenas o trecho que foi compartilhado na conversa, preservado sem alterações. Ele ainda não está completo como programa final; o cálculo da média e a listagem precisam ser revisados antes de ser apresentado como projeto concluído.
